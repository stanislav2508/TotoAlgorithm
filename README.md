# Toto Analyzer

Конзолно приложение на C# за анализ на исторически данни от Toto 6/49.

## Описание

Приложението изтегля исторически данни за Toto 6/49 чрез HTTP заявки, обработва TXT и DOCX файлове и генерира статистики и визуализации.

Проектът е разработен с:

* C#
* .NET 8
* Visual Studio
* LINQ
* HttpClient
* OpenXML SDK

# Функционалности

* Зареждане на данни по година
* Анализ на най-често срещани числа
* Анализ на най-често срещани двойки
* Разпределение на числата
* Heat Map визуализация

---

# Структура на проекта

* Program.cs -> Главно меню
* Loader.cs -> Зареждане на данни
* NotepadReader.cs -> Четене на TXT файлове
* DocumentReader.cs -> Четене на DOCX файлове
* StructureParser.cs -> Обработка на данните
* Stats.cs -> Статистики
* View.cs -> Визуализация
* Structure.cs -> Модел на данните

---

# Как работи

1. Потребителят избира година.
2. Програмата изтегля съответния файл чрез HttpClient.
3. Данните се обработват.
4. Генерират се статистики.
5. Резултатите се визуализират в конзолата.
